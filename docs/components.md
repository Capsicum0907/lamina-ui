# Components

[日本語](components.ja.md) · [README](../README.md#documentation)

The components, grouped as Material 3 groups them. Each page says what a component does, how to use it and its main values; the full values and their sources are in [Design tokens](design-tokens.md). The names of the shared protocol (`Paintable`, `Focusable`, `handle`, `step`, `paint`) are explained in [App structure](app-structure.md#widget-protocol).
