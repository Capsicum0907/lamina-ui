# データの表

[English](data-table.md) · [README](../../README.ja.md#資料)

`lamina/widgets/table.hpp`：`Table` はデータテーブルです。上に残る見出し、並べ替えられる列、見出しの区切りをドラッグして変える列の幅、一行または Ctrl と Shift での複数の選択、キーボードでの移動、縦横のスクロール、密度を持ちます。見えている行だけを並べて描くので、セルを返す関数で何行でも持てます。

Material 3 にはデータの表がありません。値は MDC Web のデータの表から取り、[表](../design-tokens.ja.md#表)にまとめています。

## 出典

- MDC Web のデータの表：<https://github.com/material-components/material-components-web/tree/master/packages/mdc-data-table>
- 値ごとのソースのファイルとコミット：[デザイントークン](../design-tokens.ja.md)
