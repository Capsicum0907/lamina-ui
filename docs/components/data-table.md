# Data table

[日本語](data-table.ja.md) · [README](../../README.md#documentation)

`lamina/widgets/table.hpp`: `Table`, a data table with a sticky header, sortable columns, column widths dragged at the header dividers, single or Ctrl and Shift multiple selection, keyboard navigation, scrolling in both directions and density; only the rows in view are laid out and painted, so it holds any number of rows given by a cell function.

Material 3 has no data table; the values come from MDC Web's data table and are listed in [Table](../design-tokens.md#table).

## Sources

- MDC Web, data table: <https://github.com/material-components/material-components-web/tree/master/packages/mdc-data-table>
- The source files and commits of every value: [design tokens](../design-tokens.md)
