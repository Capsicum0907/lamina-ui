# 描画の部品の比較：Blend2D と ThorVG

[English](renderer-comparison.md)

二つの部品で同じ `Canvas` の口を実装しています（`lamina_blend2d`・`lamina_thorvg`）。`tools/render-compare` は同じ場面を両方で描き、時間を測り、画像と 8 倍に拡大した切り抜きを書き出し、画素を比べます。

2026-11-19 に測定。Blend2D（vcpkg の 2025-03-08 版）と ThorVG 1.0.5、どちらも CPU の描画で 1 スレッド、Release ビルドです。

## 場面

1600 × 1000 px、倍率 1.25。角丸の四角 32 個（角の丸めの段階をすべて使い、3 分の 1 に影つき）、半透明で重なる円 24 個、3 次ベジェ曲線で作った星形 12 個、太さ 0.8 dp で位置が端数の細線 40 本。

## 結果

| | Blend2D | ThorVG |
|---|---|---|
| 塗りだけ | 0.82 ms/コマ | 1.77 ms/コマ |
| 影あり | 14.5 ms/コマ | 7.2 ms/コマ |

影ありの二つの画像の差は、1 チャンネルあたり平均 0.13、最大 24 で、8 より大きく違う画素は 0.05 % です。拡大した切り抜き（角・星の曲線・細線）では見分けがつきません。

## 決定

ThorVG に決めました（2026-11-19）。仕上がりは同じで、速さの差はこのコマの時間では効きません。一方 ThorVG は影とぼかしを持ち、同じ API で GPU の描画に移れます。Blend2D 版と比較の道具はこの測定の後に外しました。git の履歴（コミット `2583aaf`）に残っています。

## 注意点

- Blend2D にはぼかしの機能がありません。影は lamina-ui 側で書いたぼかし（箱型のぼかしを 3 回、`render/box_blur.cpp`）で、速くする工夫はしていません。影ありの時間は、Blend2D ではなくこのコードの時間です。
- ThorVG はぼかしと影を持っています（`SceneEffect`）。影の角度は上から時計回りに測り、ずらす量は整数の画素に丸められるので、ばねで動かすと影が 1 px 刻みで動きます。そのため lamina-ui は影の機能を使わず、影の形を端数の位置にそのまま描いてガウスぼかしをかけています（`Canvas::fill_shadow`）。
- ThorVG には同じ API の OpenGL 版と WebGPU 版の描画もあります。vcpkg の ThorVG は CPU 版だけをビルドします。
- 文字は比べていません。どちらを選んでも、日本語の文字組みには HarfBuzz が要ります。
